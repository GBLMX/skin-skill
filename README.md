# skin-skill

A pi coding agent skill for creating, editing, and rendering Minecraft player skins.

Full double-layer (hat/jacket/sleeve/pants) and Steve/Alex model support, with
realistic shading, patterns, preset templates, reference-image color sampling,
and 3D rendering.

## Requirements

- Python 3
- Pillow: `python -m pip install pillow`

## Install

```bash
pi install git:github.com/GBLMX/skin-skill
```

## Usage

See the skill: `/skill:minecraft-skin` in pi, or read
`skills/minecraft-skin/SKILL.md`.
