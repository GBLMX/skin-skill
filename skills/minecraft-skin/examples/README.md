# Example skins — provenance & licensing

The MIT license in the repository root covers the **code** (`src/skinlib/`,
`*.py`, `*.json`). The PNG files in this folder are **reference material** and
carry their own rights — they are **not** MIT-licensed.

## Original programmatic output (no third-party rights)

Generated by this library's own templates / shading / decoration code:

- `*_test*.png`, `pose_walking.png`, `launcher_skin_1*.png`
- `reference_noob.png`, `reference_medieval_knight.png`
- `cao_alarak*` — the author's original style-prompt work (a pixel-art fusion
  study), not a reproduction of any game asset.
- `necromancer.py` + `necromancer*.png` — the author's original necromancer skin
  (v3 optimized: artistic shading + skull emblem / runes / bone armor).
- `psionic_vampire.py` + `psionic_vampire*.png` — the author's original
  psionic-vampire skin (灵能吸血鬼), built on the material/overlay/style API.
- `harmonize_reference.py` — color-matching demo: measures ΔE, then matches one
  skin's palette onto another in both modes, plus a masked region. It reads the
  two `reference_*.png` above and writes its output PNGs to the current
  directory, so the repository carries no new images.
- `texture_preview.py` — texture screening demo: tiles a batch of PNGs into a
  contact sheet, and composes a generated block sheet into an isometric cube
  (pure Pillow, no renderer). It writes only to `-o` (default `previews/`), so
  it adds no bundled images either.
